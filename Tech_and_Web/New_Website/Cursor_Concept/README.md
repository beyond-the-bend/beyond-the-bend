## Design Direction

Laura likes this overall look:

- calm and premium
- spacious editorial layout
- warm neutral background
- sage, clay, rose, linen tones
- simple navigation
- not overly AI-looking
- not too template-like

The current font pairing is:

- Headings: `Literata`
- Body: `Inter`

Earlier font notes:

- Fraunces had nice spaciousness, but the J/F letterforms looked too funky.
- Instrument Serif felt too squished.
- Playfair Display was better and familiar, but less interesting.
- Literata is the current test.
