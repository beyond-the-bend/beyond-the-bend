# New Website Start Here

This is the clean workspace for the Beyond the Bend website being built outside GoHighLevel.

## Work Here Today

1. Use `Codex_Concept_Play` for all current website design and homepage work.

2. Open `Codex_Concept_Play\index.html` to view the current working home page.

3. Keep images used by this version in `Codex_Concept_Play\assets`.

4. Keep planning notes, draft copy, page order, and launch notes in `Planning`.

5. Use `Active_Build`, `Cursor_Concept`, and `Reference_From_GoHighLevel` only as source material.

## Folder Guide

1. `Codex_Concept_Play`
The official working website direction approved by Laura on June 23, 2026.

2. `Active_Build`
The earlier multi page website. Preserve it as source material while the new direction is developed.

3. `Cursor_Concept`
Cursor's untouched original one page concept. Preserve it as a design reference.

4. `Planning`
Notes for navigation, copy, page priorities, launch ideas, and design decisions.

5. `Reference_From_GoHighLevel`
GoHighLevel page material that may be useful while rebuilding the independent website.

6. `Assets_To_Review`
A holding place for images or files that might belong on the new site but still need a decision.

## Important

1. The older `Tech_and_Web\website` folder is preserved as a reference because it may still be connected to old previews or tools.

2. New independent website work should happen in `Tech_and_Web\New_Website\Codex_Concept_Play`.

3. GoHighLevel custom HTML belongs in `Tech_and_Web\GoHighLevel_Custom_HTML`.
