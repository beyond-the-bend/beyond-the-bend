# BTB Workspace Map

This map is a quick guide for where things live in the BTB folder.

## Main Homes

1. `Brand_Assets`
Images, logos, Laura photos, generated visuals, banners, and brand reference material.

2. `Content`
Written material, newsletters, Substack essays, blog posts, and workshop copy.

3. `Content\newsletters`
The official home for GoHighLevel newsletter files and newsletter images.

4. `Content\Substack`
The official home for Substack essay drafts and exported essay text.

Newsletter HTML files in `Content\newsletters` are converted through the BTB Newsletter To Substack automation and saved here as markdown drafts.

5. `Content\Workshops`
The official home for workshop planning, scripts, printable versions, and workshop page copies.

6. `Courses`
The official home for course builds and course assets.

7. `Sanctuary`
Membership material, class plans, finished videos, meditation audio, and Sanctuary master content.

8. `Tech_and_Web`
Website files, page code, GoHighLevel setup work, automations, and video processing tools.

9. `Tech_and_Web\New_Website`
The clean workspace for the new independent website outside GoHighLevel. Use `Active_Build` for page edits and `Planning` for notes.

10. `Tech_and_Web\GoHighLevel_Custom_HTML`
The home for custom HTML prepared for GoHighLevel.

11. `Business_Operations`
Strategy, legal, finance, admin systems, affiliate material, and workspace maps.

12. `Personal_Professional_Growth`
Personal development notes, reflections, and growth work.
